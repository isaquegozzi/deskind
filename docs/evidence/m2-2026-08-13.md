# Evidência M2 — 2026-08-13

## Wire format

- header v1 fixo de 32 bytes, little-endian;
- `INPUT_BATCH` com prefixo de 4 bytes e samples de 24 bytes;
- máximo 32 samples e frame de input <= 1200 bytes;
- validity flags distinguem zero real de campo ausente;
- tilt Android permanece tilt+orientation; conversão Win32 fica em M4.

Fonte de verdade: `docs/protocol.md`.
